- **01 — LISTEN**: Understand client objectives, market parameters, and targets.
- **02 — THINK**: Collaborative in-house strategic analysis and concept exploration.
- **03 — SOLVE**: Select the most effective, revenue-driving creative solution.
- **04 — EXECUTE**: Rigorous execution backed by technical excellence on budget and on time.
- **05 — LAUNCH**: Strategic market rollout across ATL, BTL, and digital touchpoints.

## 🛠️ Tech Stack & Architecture

- **Zero Heavy Framework Bloat**: Pure, accessible HTML5, modern CSS3 (Custom properties/design tokens, Grid, Flexbox, Container queries), and vanilla JavaScript.
- **SEO & Schema.org**: Fully validated JSON-LD (`AdvertisingAgency`, `LocalBusiness`, `PostalAddress`, `GeoCoordinates`, `Service`, `BreadcrumbList`, `BlogPosting`).
- **Core Web Vitals & Accessibility**: Fluid responsive typography (`clamp()`), sub-50ms interaction latency, WCAG AA compliant contrast, full keyboard navigation, and reduced-motion support.
